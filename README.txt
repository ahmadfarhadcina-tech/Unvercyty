نمونه آزمایشی صفحه نتایج کانکور افغانستان
========================================
فایل‌ها:
- index.html : ساختار صفحه
- style.css  : طراحی آبی تیره، واکنش‌گرا و اسلایدشوی عکس‌ها
- script.js  : تعویض نرم عکس‌ها و پیام فرم آزمایشی

اجرا:
1) هر سه فایل را در یک پوشه نگه دارید.
2) index.html را در مرورگر باز کنید.
3) برای عکس‌های پس‌زمینه و فونت آنلاین، اتصال اینترنت لازم است.

مهم:
- این پروژه به دیتابیس متصل نیست.
- هیچ نتیجه‌ای تولید یا نمایش داده نمی‌شود.
- عکس‌ها از منابع بیرونی بارگذاری می‌شوند؛ پیش از انتشار عمومی، مجوز استفاده از هر تصویر را بررسی کنید.
- این نمونه وب‌سایت رسمی اداره کانکور افغانستان نیست.
